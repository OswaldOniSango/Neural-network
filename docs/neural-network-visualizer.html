Formula real de cada neurona oculta

Primero se calcula la suma ponderada z. Luego se aplica la sigmoide: sigmoid(z) = 1 / (1 + e^-z). Eso comprime el valor al rango 0..1.

Formula real de la salida

La salida final no usa sigmoide. Es lineal, por eso puede aproximar mejor una suma como 1.3, 1.8 o 2.0.

3. Como fue el entrenamiento

El codigo Java entrena la red con ejemplos como [0.3, 0.4] -> 0.7. En cada epoca, la red hace una prediccion, calcula cuanto se equivoco y mueve un poco sus pesos para acercarse al resultado correcto.

1

Inicializacion aleatoria

Los pesos arrancan con valores aleatorios entre -1 y 1. Al principio la red no sabe sumar.

2

Forward pass

Las entradas pasan por la capa oculta. Cada neurona combina entradas, pesos y bias, y luego aplica sigmoide.

3

Error de salida

El error es esperado - predicho. Si la red da menos de lo correcto, varios pesos deben aumentar.

4

Backpropagation

Ese error se reparte hacia atras. Asi cada neurona oculta recibe una senal de cuanto colaboro en el error.

5

Actualizacion

El codigo ajusta pesos y biases con la regla: nuevo = viejo + learningRate * correccion.

6

Repeticion

Esto se repite por 20000 epocas. Poco a poco la red encuentra una combinacion que aproxima la suma.

Las formulas del entrenamiento en tu codigo

outputError = esperado - salida

hiddenError[j] = (outputError * weightHiddenOutput[j]) * hidden[j] * (1 - hidden[j])

weightHiddenOutput[j] += learningRate * outputError * hidden[j]

weightInputHidden[i][j] += learningRate * hiddenError[j] * input[i]

Eso es justamente backpropagation con descenso por gradiente en una red chica de regresion.

Ojo con el alcance del entrenamiento

Esta red fue entrenada con solo 12 ejemplos, todos en el rango 0.0 a 1.0. Dentro de ese rango suele aproximar bien la suma. Fuera de ese rango no hay garantia: la red no "entiende" matematicamente la suma, solo aprendio un patron numerico a partir de esos datos.
