1. Variables del modelo

Estas son las variables cargadas en el modelo. predict() las usa. Durante train(), estas mismas variables se actualizan.

2. Cuando la probas: predict()

Esta parte explica el camino normal de prueba. Aca no se aprende nada: solo se toman inputs, se calcula hidden y al final se calcula outputs[0].

3. Cuando entrena: train()

Esta parte sigue el mismo orden del metodo train(...): toma un sample, crea inputs, expected, hidden, outputs, hace forward pass, calcula errores y recien despues actualiza pesos y bias.
